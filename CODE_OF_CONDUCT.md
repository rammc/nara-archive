# Code of Conduct

`actari` adopts the [Contributor Covenant, version 2.1][cc-2-1] as its code
of conduct.

The full text is canonical at the URL above; we follow it as-written rather
than maintain a local copy that could drift over time.

## TL;DR

- Treat everyone with respect. Be welcoming.
- Disagreements are normal — keep them about ideas, not people.
- Behaviour that targets, harasses, or excludes others is not welcome.
- This applies in issues, pull requests, discussions, and any other space
  the project uses.

## Reporting

If you witness or experience behaviour that violates the Covenant in any
`actari` space, please email **<hello@cramm.dev>** with a short summary
and links if applicable. Reports are treated confidentially.

We aim to acknowledge reports within **7 days** and take appropriate
action depending on severity, ranging from a private clarifying
conversation to a permanent ban from the project's spaces.

## Scope

The Covenant applies to:

- This GitHub repository (issues, PRs, discussions, code reviews).
- Any official communication channel announced from this repository.
- Public spaces where someone is representing the `actari` project.

It does **not** extend to general internet behaviour outside `actari`
spaces — but be aware that repeated bad behaviour elsewhere may inform
moderation decisions here.

[cc-2-1]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
