Welcome to actari

A two-minute setup, then you're ready to search the National Archives Catalog.

  1. 1. Paste your NARA API key

    Free for research; request at archives.gov/research/catalog/help/api (email Catalog_API@nara.gov with a one-sentence description of your project).

    We'll make one test request to confirm the key works.

  2. 2. Choose where downloads land

    PDFs, manifests, and run logs all live here. The default works on most machines.

  3. 3. Acknowledge NARA's terms of use

    This tool uses the National Archives Catalog API but is not endorsed by the National Archives and Records Administration. NARA grants 10,000 API requests per key per month and asks consumers to keep usage polite. For full-archive bulk transfers (millions of files), NARA recommends the AWS Open Data mirror instead. This tool defaults to 0.5 seconds between requests and never parallelises downloads.
